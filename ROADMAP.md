# Roadmap

## v0.2 — terminal polish

- Manual review/tuning of high-risk ASCII glyphs in Bold and Italic
- Real-world screenshots in Foot, Ghostty and Kitty at 16/32 px raster-aligned sizes
- Check punctuation/brace collision in dense code
- Check italic overhang in adjacent-cell rendering
- Tune Bold weight after WRGB/OLED and grayscale-AA comparisons

## v0.3 — AcPlus parity

- Import/recreate the remaining expanded AcPlus glyph repertoire (~780 total)
- Preserve identical cmap coverage across all four faces
- Add Greek/Cyrillic/Hebrew/extended Latin style review

## v0.4 — optional terminal extras

- Additional Powerline glyphs
- More box-drawing/heavy-line forms where CP437 does not have an exact source glyph
- Optional Nerd Font patch build (kept separate from the clean base family)
